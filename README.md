# ShopSphere

ShopSphere is a responsive e-commerce web application built with React and Vite. It provides a modern shopping experience with product browsing, shopping cart management, quantity controls and checkout functionality.

## Features

- Product listing
- Add products to cart
- Remove products from cart
- Increase and decrease product quantity
- Shopping cart management
- Checkout functionality
- Responsive design
- Modern user interface

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
