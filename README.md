# ShopSphere

ShopSphere is a responsive e-commerce web application built with React and Vite. It provides a modern shopping experience with product browsing, search and filtering, wishlist management, shopping cart functionality, checkout validation, and order confirmation.

## Features

* Product listing
* Product search
* Category filtering
* Product sorting
* Product details view
* Add products to cart
* Increase and decrease product quantity
* Remove products from cart
* Shopping cart management
* Wishlist functionality
* Checkout validation
* Order confirmation
* Cart and wishlist data stored using localStorage
* Responsive design
* Modern user interface

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Vite
* Git & GitHub

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/nayakbk7991-sys/ShopSphere.git
```

### 2. Navigate to the project folder

```bash
cd ShopSphere
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal.
